# INAVAE

Aplicacion web responsive para la gestion de actividades de una iglesia.

## Alcance actual

El proyecto se encuentra en la Fase 1. La base usa Next.js, TypeScript, React, Tailwind CSS, Prisma y PostgreSQL. Todavia no se implementaron autenticacion, entidades del dominio ni pantallas del MVP.

## Reglas de trabajo

- Mantener la autorizacion en el servidor.
- Usar `America/Argentina/Buenos_Aires` como zona horaria oficial.
- No guardar secretos en el repositorio.
- No eliminar fisicamente actividades desde la interfaz normal.
- Mantener personas inactivas con historial.
- No avanzar a una fase funcional importante sin aprobacion.
- Agregar validacion y pruebas para cada funcionalidad.
